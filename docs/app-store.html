K-Capture
Mac App Store edition

필요한 화면을 캡처하고,
바로 정리하세요.

K-Capture는 이미지·스크롤·동영상 캡처와 주석, 플로팅 뷰, 동영상 타임라인 편집을 한곳에서 제공하는 macOS 앱입니다.

Mac App Store가 설치와 업데이트를 관리합니다

K-Capture App Store판은 앱 안에서 업데이트 파일을 확인하거나 내려받아 교체하지 않습니다.

주요 기능

이미지·스크롤 캡처

필요한 영역이나 긴 화면을 캡처해 로컬 보관함에서 바로 확인합니다.

동영상 캡처와 편집

선택한 영역을 녹화하고 구간 편집·음량 조절 후 MP4로 저장합니다.

주석과 정보 가리기

펜, 도형, 텍스트, 블러와 모자이크로 전달할 화면을 정리합니다.

항상 위 플로팅 뷰

참고할 이미지와 동영상을 다른 작업 위에 띄워두고 확인합니다.

데이터와 권한

캡처 결과와 설정은 사용자의 Mac 안에 저장되며 분석·광고·계정 서비스를 사용하지 않습니다. 화면 기록 권한은 캡처에, 마이크 권한은 사용자가 마이크 포함 녹화를 선택한 경우에만 사용합니다.
