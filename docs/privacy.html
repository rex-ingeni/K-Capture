수집하는 데이터

K-Capture는 계정, 이메일, 연락처, 위치, 사진 보관함 정보를 수집하지 않으며 분석·광고 SDK를 사용하지 않습니다. 캡처 파일과 권한 상태도 외부로 전송하지 않습니다.

로컬 저장

이미지, 동영상, 썸네일, 즐겨찾기와 설정은 앱의 Sandbox 컨테이너에 저장됩니다. 사용자가 내보내기를 선택하면 지정한 위치에 PNG 또는 MP4 파일을 만듭니다.

외부 통신

App Store판은 자체 업데이트 확인·다운로드·설치를 하지 않으며 앱 기능을 위한 네트워크 통신도 하지 않습니다. 사용자가 설정에서 개인정보 처리방침이나 고객 지원을 누른 경우에만 기본 브라우저가 이 공개 문서를 엽니다.

권한

  • 마이크: 사용자가 시스템 오디오와 마이크를 함께 녹화하도록 선택한 경우에만 요청합니다.

Privacy Policy

Last updated: August 6, 2026

K-Capture does not transmit captured images, video, or audio outside your device.

Data collection

K-Capture does not collect accounts, email addresses, contacts, location, or photo library data and includes no analytics or advertising SDKs. Captures and permission status are not transmitted.

Local storage

Images, videos, thumbnails, Favorites, and settings are stored in the app's Sandbox container. PNG or MP4 files are created elsewhere only when the user explicitly exports them.

Network and permissions

The App Store edition does not check for, download, or install updates and performs no network communication for app features. Screen Recording is used for capture. Microphone access is requested only when the user selects recording with a microphone.

Deletion and contact

Deleting an item from the app library removes its related local files. Contact: ingeni@kakao.com
