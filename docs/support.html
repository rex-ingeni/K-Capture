When contacting support

Include your macOS version, K-Capture version, the feature involved, reproduction steps, and an error message or screenshot with personal information removed.

Permissions

If capture does not work, verify K-Capture under System Settings → Privacy & Security → Screen & System Audio Recording. Recording with a microphone also requires Microphone permission.

System requirements

macOS 13 or later.
